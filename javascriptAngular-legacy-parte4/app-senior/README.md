# App de prueba — Gestión de Empleados / Nómina (AngularJS 1.8)

## Cómo ejecutar
Abre `index.html` en el navegador (requiere internet para cargar AngularJS desde CDN).
Los datos son simulados en memoria — no necesitas backend.

## Tus tareas
Las tareas están descritas en la Parte 4 del enunciado de la prueba.
Entrega la carpeta con tus correcciones, el componente migrado a Angular moderno
y un archivo `NOTAS.md` explicando cada problema encontrado, su causa raíz
y la solución aplicada. Abre la consola del navegador — hay pistas ahí.
